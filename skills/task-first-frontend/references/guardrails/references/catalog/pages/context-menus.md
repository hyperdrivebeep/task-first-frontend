## Context menus

Universal rules:

- MUST keep a context menu short, with a small number of items that can be scanned without scrolling. | topic: Context menus | source: https://developer.apple.com/design/human-interface-guidelines/context-menus | why: A long menu is hard to scan and I may miss the item I need. | check: open the context menu on a list item at 1440px and at 390px; all items are visible without scrolling.

- MUST make every context menu command also available in the main interface, such as a toolbar or the app's menus. | topic: Context menus | source: https://developer.apple.com/design/human-interface-guidelines/context-menus | why: Commands are not hidden behind a gesture I may not know about. | check: open the context menu and the main view's toolbar at 1440px and 390px; every context menu item has a matching control in the main interface.
- MUST limit submenus in a context menu to one level. | topic: Context menus | source: https://developer.apple.com/design/human-interface-guidelines/context-menus | why: Nested submenus are hard to navigate and I can get lost. | check: open the context menu and every submenu at 1440px and 390px; no submenu contains another submenu.

Apple-specific (excluded):
- Reveal gestures tied to Apple input: touch and pinch hold in visionOS, iOS, and iPadOS; Control-click in macOS; secondary click on a Magic Trackpad.
- Edit menu pairing: provide either a context menu or an edit menu for an item, not both (refers to Apple's edit-menus component).
- Red text color the system applies to destructive menu items.
- Use of the system's standard icon set (icons#Standard-icons) and the requirement to match system icons.
- System animation details: the system dims the background and animates the preview out of the content.
- visionOS window system components, such as window-management controls and the Share menu.
- Apple app examples: Mail, Notes, Files, and the Mail Mark toolbar button.
- macOS terms and behavior: "contextual menu" name, menu bar listing all commands, and Cut, Copy, and Paste possibly appearing unavailable.
- Platform support statements: no additional tvOS considerations; not supported in watchOS.
- Apple developer APIs: contextMenu(menuItems:), UIContextMenuInteraction, popUpContextMenu(_:with:for:).

Persona and journey notes:
- People often do not know a context menu exists because it is hidden by default, so the same commands must also be reachable in the main interface.
- A person doing a few simple actions wants a short menu that is quick to scan; a specialist doing in-depth tasks may accept a large set of commands.
- A person choosing an item from a list should see a preview that confirms they are acting on the right item.
